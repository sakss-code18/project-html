# Personal Portfolio Website

This is my first web development project — a personal portfolio website built to showcase my skills, projects, and contact information in a clean and simple layout.

## 🌐 About the Project
The portfolio introduces who I am, highlights my technical skills, and provides an easy way for visitors to contact me. It is designed to be beginner-friendly, responsive, and easy to navigate.

##  Features
- Clean and minimal UI design
- Sections for:
  - Home
  - About Me
  - Skills
  - Projects
  - Contact
- Dark Mode toggle
- Contact form UI

##  Technologies Used
- HTML5
- CSS3
- JavaScript

##  Preview
This project includes:
- A hero section with introduction
- About me section describing my interests
- Skills section showcasing my core technologies
- Contact form for user interaction

##  Future Improvements
- Add backend functionality to contact form
- Improve UI/UX with animations
- Add more projects section
- Deploy the website using GitHub Pages
